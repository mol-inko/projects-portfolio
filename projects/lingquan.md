# 凌泉 · 长期自主运行的 AI Agent

> 状态：**长期运行**（云服务器常驻）
> 形态：带人格、记忆与真实动作能力的个人 Agent

## 它是什么

一个不是「聊天框」的 Agent：有自己的记忆、会按计划自己去读东西、会写记忆、会自测记忆，还会发视频。

名字取自《魔女的夜宴》——但工程上它是一个跑在云服务器上的长期进程，不是 demo。

## 架构

```
┌─────────────────────────────────────────┐
│              调度层（timers）            │
│   每日巡查 / 阅读 / 记忆 / 自测 / 投稿    │
└───────────────┬─────────────────────────┘
                │
┌───────────────▼─────────────────────────┐
│              Agent 核心                  │
│  任务规划 · 工具调用 · 输出校验 · 失败重试 │
└───────────────┬─────────────────────────┘
                │
   ┌────────────┼────────────┬─────────────┐
   ▼            ▼            ▼             ▼
 四层记忆      B 站链路      QQ 链路      视频管线
```

## 四层记忆

| 层 | 内容 | 写入方式 |
|---|---|---|
| `episodes` | 每次行动发生了什么 | 追加 |
| `facts` | 抽取的事实 | 追加 + 版本 |
| `understanding` | 对世界的理解 | 版本化追加 |
| `self` | 自我认知 | 版本化追加 |

关键：**跨会话保持一致**——换一次上下文，人格、事实与自我认知不会漂。

## 记忆评测闭环

这是我认为最有意思的一块：

```
每日 巡查 → 阅读 → 写记忆 → 次日闭卷自测
                              ↓
                    用自测得分反向验证「记忆写入是否真的被模型记住」
```

大多数 Agent 的「记忆」只是存了，不知道有没有用。这里用**次日闭卷考试**当验收——记错了、写丢了、检索不到，都会在分数上露出来。

## 工具调用与真实动作

- **QQ 双向机器人**：NapCat + OneBot + 自研桥接，只对主人 1v1
- **B 站链路**：自动巡查 → 阅读 → 记忆 → 投稿（白名单约束）
- **视频管线**：Edge-TTS 句子级时间轴 + Remotion 代码动画 + 音画同步校验，自动成片
- **预算与自愈**：token 预算监控、掉线看门狗、失败重试

## 部署

- 阿里云 4C/8G，systemd + timers
- 服务、定时任务、日志与健康检查全部脚本化

## 技术栈

Python / LLM API · SQLite / JSONL 记忆层 · systemd / timers · NapCat / OneBot · Edge-TTS / Remotion · 阿里云
